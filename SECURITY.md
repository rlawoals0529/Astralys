# Security

Astralys is a pre-release local-first application. Only the current development branch is maintained; there are no supported public releases yet.

Until a verified private reporting channel is available, do not post exploit details, real user documents or secrets to public issues. Ask the maintainer for a private channel in an issue containing only a request to report a vulnerability. Once GitHub private vulnerability reporting is enabled, use the repository Security → Report a vulnerability flow. Availability must be verified before public release; it is not claimed enabled now.

Provide affected revision, browser/OS, impact and a minimal synthetic reproduction through the agreed private channel. Never submit personal files or credentials. There is no promised response SLA or bug bounty.

See docs/security/THREAT_MODEL.md for limits, trust boundaries and release gates. Local processing and automated tests do not guarantee that a malicious file is safe.
