# Architecture decisions

1. **TypeScript + Vite, native DOM shell.** This small workflow does not justify a UI framework. Typed domain logic is separate from DOM. No production npm dependencies. Vitest tests boundaries; Playwright tests built output in Chromium and Firefox. ESLint/TypeScript check source. Pin TypeScript to an ESLint-supported 6.0 release rather than blindly selecting 7.x.
2. **One File → relevant actions → result.** Categories are navigation and honest capability descriptions, not a wall of inactive converters. Images have working actions. PDF and other categories explain planned capabilities without fake action buttons.
3. **Worker-owned processing.** File size and header checks precede createImageBitmap. OffscreenCanvas performs transforms and encoding. Blob goes back to UI; previews use only re-encoded output. UI worker controller owns deadlines, cancellation, one active job and object URLs.
4. **No implicit persistence.** A File and editor parameters exist in memory until Clear/reload. No IndexedDB/OPFS in V1: a 20 MiB cap does not justify persistent file storage. Later large-file workflows may offer explicit opt-in temporary OPFS, quota detection and guaranteed cleanup. File System Access APIs are not required; portable file input/download is the baseline.
5. **Photo foundation and upstream spike are separate.** Single-image rotation/flip/undo/reset are native operations. The PhotoCraft integration spike evaluates color math without importing egui, fonts, UI branding or a full parser graph. It is not a full layer/PSD editor and does not enable in production.
6. **Future compute service.** Provider policy gate → allowlisted network broker → ephemeral isolated worker. Browser work stays local. Explicit consent and retention disclosure precede any future upload. No backend runtime chosen until there is a measured requirement; no heavy media job assumed feasible on Cloudflare Workers.
7. **Static delivery security.** Build emits static assets. A local verification server sets strict CSP and other headers. `public/_headers` records equivalent hosting requirements. No deployment or hosting registration is part of this milestone. The dev server requires a looser connect policy for HMR; browser security tests use production output.
8. **Metadata scope.** Inspection shows file type/size, dimensions and metadata container presence, not arbitrary EXIF values. Sanitized export strips supported metadata containers. JPEG transparency is flattened on white with a visible warning; encoding is not guaranteed smaller. Animated PNG/WebP rejected; unsupported encode format must fail rather than silently return PNG.
