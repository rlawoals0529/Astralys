# Naming decision

User selected **Astralys** on 2026-10-09, after requesting names with a mythological/fantasy feel like Ariadne. Use it as the private development name. No trademark clearance is claimed.

Early candidates: Ergania, Daedala, Arachne, Eidos, Mneme, Asteria. GitHub name searches returned respectively 1, 6, 620, 675, 428 and 979 matches on the review date (substring matches, not unique trademark searches). Fantasy candidates: Velthira, Thalune, Myravel, Ilyrion, Vaelora, Auralith. The first two had obvious brand/app uses; others had existing fiction or commercial uses or incomplete screening. These are proposals, not claims of invented/unused words.

Astralys searches found multiple GitHub repos (including abundanceslots/Astralys, Valnan86/Astralys and barbarahaggi/astralys), software-business usage by Astralys LLC, and SWGT Astralys. Sources:
- https://www.mql5.com/en/market/product/163926
- https://astralys.swgt.io/controllers/common/viewCredits
- https://github.com/search?q=Astralys&type=repositories

A matching repository name in another account does not prevent a private personal repo. Public product naming remains unresolved; conduct appropriate trademark/domain/common-law searches in target markets before launch. No upstream or third-party logo, wordmark or visual identity is reused.
